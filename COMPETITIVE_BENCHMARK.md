## 2. Architectural Patterns Safely Adopted (Using Original AegisμG Data Only)

1. **Strict Provenance Classification & Refusal Logic:** Adopted structured evidence labels (`NASA_OBSERVED` .. `UNVERIFIED` + `NEEDS_SOURCE_CHECK`) and automatic abstention (`"Insufficient verified NASA evidence for this conclusion."`) inside `src/utils/evidenceEngine.ts`.
2. **Explicit Empirical Gap Matrix:** Built `buildEvidenceGapMap` covering `OBSERVED` vs `SOURCE_METADATA_ONLY` vs `NO_MEASUREMENT` (`0.165 g` Lunar, `0.38 g` Martian, segment-level O2) vs `HYPOTHETICAL_MODEL`.
3. **Offline Deterministic BM25 Question Explorer:** Built `answerResearchQuestion` operating 100% locally without API keys and tested against 8 grounded questions plus 4 forbidden unverified queries.
4. **Judging-Ready 7-Slide Self-Contained HTML Deck:** Created `submission/presentation.html` matching the official ≤30s / ≤7-slide rule.

*No source files, weights, scraped datasets, or assets were copied from any competitor project.*
